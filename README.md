# AgeTech Launch Market Finder

Where should you build your next AgeTech company? Answer a few questions and see how every US county scores as a launch market, from 0 to 100.

Data: Urban Institute, Metrics Data for the Aging Opportunity Dashboard (ODC-BY 1.0); U.S. Census Bureau population estimates, Gazetteer, County Business Patterns and county boundaries; CMS Medicare Advantage and nursing home files; USDA ERS Rural-Urban Continuum Codes. Data as of November 2026.

This folder is generated by `build_site.py`; edit the source files, rebuild, then push.
